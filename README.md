## ⚙ Installation & Setup

1️⃣ Clone the repository

git clone https://github.com/VinayakLengare/react-portfolio.git

2️⃣ Navigate to project folder

cd react-portfolio

3️⃣ Install dependencies

npm install

4️⃣ Start development server

npm run dev
